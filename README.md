# Corporate Banking Backend

## Overview

Corporate Banking Backend is a REST API designed for business (corporate) customers. It enables companies to perform and manage their banking operations through secure and scalable APIs.

## Features

- Create account aliases
- Receive payments
- Return payments
- Send payments
- Execute bulk payments
- Submit payment cancellation requests
- Submit payment requests
- Submit bulk payment requests
- Retrieve the list of operations
- View operation details
- Transfer funds between company accounts

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Docker
